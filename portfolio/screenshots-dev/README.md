# Myszy — screeny DEV do portfolio

Ta paczka zawiera screeny z konta demonstracyjnego `Myszy DEV`. Dane na ekranach są fikcyjne i służą wyłącznie do pokazania przepływu aplikacji.

## Zebrane ekrany

1. `01-home-balance.png` — norka i bilans
2. `02-history.png` — historia wydatków
3. `03-profile-beta.png` — profil i ustawienia Beta
4. `04-settlement.png` — wyrównania
5. `05-add-expense.png` — dodawanie wydatku
6. `06-import-pdf.png` — pierwszy etap importu PDF
7. `07-import-second.png` — kolejny wpis do zatwierdzenia
8. `08-receipt-preview.png` — fikcyjny paragon DEV
9. `09-login.png` — logowanie
10. `10-privacy.png` — „Prywatność w aplikacji Mysze”
11. `11-password-reset.png` — odzyskiwanie hasła
12. `12-signup.png` — zakładanie konta

Przed publicznym użyciem screenów wykonujemy jeszcze szybki przegląd: brak prywatnych adresów e-mail, tokenów, kodów zaproszeń i danych z prawdziwych urządzeń. Screeny z numerami 01–12 są już zebrane z emulatora DEV; nie pochodzą z prywatnej wersji aplikacji. Ekran parowania i ekran powitania po zalogowaniu zostawiamy do osobnej sesji z kontrolowanym kontem DEV, żeby nie tworzyć przypadkowych danych podczas tej paczki.
